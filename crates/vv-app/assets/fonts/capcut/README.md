# Reference fonts

These files were copied from the user's local CapCut text reference project.
`sources.json` maps the original filenames to their internal family names.
They are kept apart from the OFL fonts in the parent directory; the parent's
OFL notices do not describe these imported files.

The Wide face declares weight 40 and Metropolis declares weight 500.
Templates must request these actual weights: cosmic-text otherwise silently
falls back to a different family. ZY Resolve has a single face at weight 400,
which is also the weight used by the Pop subtitle template.
